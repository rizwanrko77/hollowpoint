The obstacles are the test. They are not a requirement.

This application flow leans on hovering links, reading response headers, and using browser developer tools. Those are choices we made, and they are not equally available to everyone. If any part of it is unworkable for you — for any reason, and you do not have to tell us which — there is a direct route to the same form.

Email access@hollowpoint.example with the reference RE-8FF31. You get the plain link back, usually the same day. Nothing is recorded about the request and it does not affect how your application is read. Candidates who come in this way are assessed on the application itself, which is what we wanted to assess in the first place.

The same applies if you are simply out of patience. We would rather read your application than lose it to a puzzle.
